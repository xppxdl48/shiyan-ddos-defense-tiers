## 十堰这个机房，优势在哪，短板在哪

优势集中在三点。

位置。十堰在湖北西北，连着鄂陕豫，走电信骨干直连华中与华东，全国访问延迟不算垫底。雨云官方论坛放出的实测数据里，十堰机房的平均延迟在 27ms 上下，最快的湖北武汉电信只有 6ms 左右。

防御。电信高防集群是十堰的主力卖点。按产品和配置不同，防御从 100G 到 800G 都能拿到，属于「一个独立 IP 就把攻击流量接过去清洗」的模式，不需要自己再套 CDN。

价格。十堰的入门档确实便宜。雨云的流量计费型云服务器在十堰最低 10 元/月就有 2 核 2G 加 200G 防御，带 400G 防御的电信单线机 60 元/月起。

短板也说清楚，免得买完才发现不对。

十堰以电信单线为主，雨云后来补上了三线 BGP 线路，跨网质量比纯电信单线好，但如果你主要用户是移动、联通且业务极度吃延迟，江苏宿迁或浙江宁波的 BGP 节点通常更稳。另外十堰的大带宽机型走流量计费，流量用完会限速，这一点后面单独说。

## 选型前必须先定的三件事

**第一件：你防的是哪类攻击。** 十堰的防御额度说的是 DDoS 流量清洗，100G、200G、400G、800G 都是按这个口径。如果是 CC 攻击打应用层，靠的是机房的清洗策略加上你自己在服务器上做限速和 WAF，单纯堆防御数字没用。

**第二件：带宽要按流量算还是按峰值算。** 雨云十堰有两种计费形态：一种是「大带宽限流量」，上下行给到 50M 到 100M，但每月有流量额度；另一种是「小带宽不限流量」，带宽数字小一些，但流量随便跑。前者适合有峰值但总量不大的站点，后者适合长期跑流量的服务端。

**第三件：要不要独立 IP、要不要开 25 端口。** 高防独立 IP 是要单独加购的，价格按机房和线路不同。自建邮局的话端口更关键，有在宝塔论坛发帖的用户提到，雨云湖北区域开放 25 端口，这也是他把邮局放在十堰的原因之一。

## 买之前必须知道的几条限制

**流量用完不是断网，是限速。** 流量计费型的机型，每月额度用尽后会被限速到 5Mbps，不会停机。用不完的流量可以结转到下个月，不受清零影响。需要恢复高速可以单独充值流量，公开的充值档位是 300G/20 元、1024G/50 元、2048G/100 元。

**大陆业务要备案加过白。** 十堰属于中国内地机房，拿它做有域名的 HTTP 站，域名要先备案并在机房过白之后才能用域名访问。纯数据库、开发测试、游戏服务端这类不依赖域名访问的业务，不受这条影响。

**硬盘扩容有上限和单价。** 高速固态按 0.4 元/G/月计，单盘最高 250G；机械盘 0.1 元/G/月，最高可到 2TB。买之前按业务实际数据量估一下。

**违规内容会被直接停服且不退款。** 挖矿、钓鱼、金融诈骗、翻墙、端口扫描、代理发包这些都在禁止清单里，这条基本是行业共识，不必指望例外。

**退款和试用政策。** 雨云支持 7 天内无理由退款，每个账号限 3 次；云服务器和游戏云可以通过 1 元试用一天（部分较贵的产品试用价会高一些），裸金属物理机的试用价是 20 元一天。不确定配置合不合适的话，用试用把业务跑一遍比看参数表靠谱。

## 什么情况下不该选十堰

主用户在华东、对跨网延迟极其敏感的，宿迁或宁波的 BGP 节点更合适。业务完全不需要防御、只想压低成本的，海外节点或者纯 BGP 国内节点通常更便宜。跑需要 GPU 的任务，就该去看雨云的显卡云产品线，十堰不是那类机器的主场。

十堰的定位很清楚：华中位置、电信高防、价格在同类里偏低。你要的是这三样，它就合适。

## 常见问题

**十堰高防服务器一个月多少钱？**

按雨云当前的公开价格，流量计费型云服务器 10 元/月起，400G 防御的电信单线高防云服务器 60 元/月起，裸金属物理机 498 元/月起。年付有额外折扣。

**100G 防御够用吗？**

取决于你的业务会不会成为攻击目标。普通企业站和小型应用，100G 到 200G 基本够用。游戏服、电商这类高频被打的业务，建议直接上 400G 以上，十堰最高可以到 800G。

**十堰机房支持哪些系统？**

云服务器支持 Linux 和 Windows，可以一键安装 1Panel、MCSManager、Docker 等环境。十堰也是雨云少数可以选到 MacOS 系统的区域之一。

**能申请 IPv6 吗？**

免费支持 IPv6，三线 BGP 线路下高防 IPv4 属于加购项目。

**配置能改吗？**

云服务器支持在线弹性升降配，CPU、内存、硬盘、带宽、流量都能调。物理机的内存、硬盘、显卡、带宽可以联系客服定制。

如果你现在正在被打，或者刚被攻击打醒，先把防御档位和计费模式这两件事定下来，再去比价格。选错计费方式，比选错防御数字更容易让账单失控。
